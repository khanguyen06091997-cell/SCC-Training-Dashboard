Kéo thả file dữ liệu đào tạo vào đây

Thả file SCC_Training_Data.xlsx vào bất kỳ đâu trên trang, hoặc bấm để chọn file. Có thể chọn nhiều file cùng lúc (ví dụ mỗi năm 1 file).

Kiểm tra dữ liệu của file đang mở

Cách dùng

  1. Nhập dữ liệu mọi năm vào cùng file SCC_Training_Data.xlsx: gõ thêm dòng ngay dưới bảng ở sheet Lop hoc và Training Record. Năm được lấy từ cột Ngày bắt đầu / Ngày học.
  2. DS Nhan vien giữ cả người đã nghỉ (ghi Ngày nghỉ việc, không xóa dòng) để headcount các năm cũ tính đúng.
  3. Mở link, bấm Chọn file… hoặc kéo thả file. Nếu dữ liệu tách nhiều file (mỗi năm 1 file), chọn tất cả cùng lúc – trang tự gộp.
  4. Sửa Excel xong, lưu file rồi bấm Làm mới. Trình duyệt cho phép thì trang đọc lại ngay; nếu không, hộp chọn file mở ra – chọn lại file là xong.
  5. Chọn Năm và So sánh với một năm khác: thẻ chỉ số hiện mức tăng/giảm, biểu đồ theo tháng hiện 2 năm cạnh nhau.

Trang tự tính lại từ các cột nhập (không phụ thuộc công thức trong file). Không đổi tên sheet, tên cột và dòng tiêu đề trong file. Đóng trang là dữ liệu biến mất; mỗi lần xem cần tải lại file.
