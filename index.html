Kiểm tra dữ liệu của file đang mở

Cách dùng

  1. Nhập dữ liệu mọi năm vào cùng file SCC Training Record.xlsx: gõ thêm dòng ngay dưới bảng ở sheet Lop hoc và Training Record. Năm được lấy từ cột Ngày bắt đầu / Ngày học.
  2. DS Nhan vien giữ cả người đã nghỉ (ghi Ngày nghỉ việc, không xóa dòng) để headcount các năm cũ tính đúng.
  3. Mở link, bấm Chọn file… hoặc kéo thả file. Nếu dữ liệu tách nhiều file (mỗi năm 1 file), chọn tất cả cùng lúc – trang tự gộp.
  4. Sửa Excel xong, lưu file (Ctrl+S) rồi bấm nút cam Làm mới: trang tự đọc lại chính file đang mở, không cần chọn lại. Lần đầu trình duyệt có thể hỏi quyền xem file – chọn Cho phép (nên chọn "cho phép mỗi lần truy cập" để lần sau mở link là tự tải). Dùng Chrome hoặc Edge.
  5. Bấm Tải PDF để lưu toàn bộ dashboard (4 tab, theo bộ lọc đang chọn) thành 1 file PDF gửi báo cáo.
  6. Chọn Năm và So sánh với một năm khác: thẻ chỉ số hiện mức tăng/giảm, biểu đồ theo tháng hiện 2 năm cạnh nhau.

Trang tự tính lại từ các cột nhập (không phụ thuộc công thức trong file). Không đổi tên sheet, tên cột và dòng tiêu đề trong file. Đóng trang là dữ liệu biến mất; mỗi lần xem cần tải lại file.
